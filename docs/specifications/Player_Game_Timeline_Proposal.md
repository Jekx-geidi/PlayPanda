Oo po, kana nice kaayo. Mao na ang makahatag ug **FB-style timeline**, pero instead of random personal posts, ang focus gyud kay **game history, wins, matches, tournaments, teams, ug actual sports moments**.

Akong proposed feature name:

# PlayPanda Game Timeline

Every user naa siyay own timeline sa profile.

Pero ang posts ideally connected sa **real PlayPanda match history**, para dili murag generic social media.

## Main idea

After mahuman ang match:

```text
MATCH FINAL
   ↓
Result Verified
   ↓
PlayPanda asks:

"Share this match on your timeline?"

[ CREATE POST ]
[ NOT NOW ]
```

If mo-post siya:

```text
Riel Jake
🏸 Badminton • Men's Singles

🏆 WON
Riel vs Juan
21–17 • 21–18

PlayPanda Open 2026
September 25

[ Match Photo ]
[ Match Photo ]
[ Match Photo ]

"Good game today. Tough second set!"

#Badminton
#PlayPanda
#GameDay
#PlayPandaOpen
```

Then naa sa bottom:

**❤️ Like   💬 Comment   ↗ Share**

Very familiar like Facebook, pero game-centered.

---

# 1. Optional gyud ang posting

Importante ni.

Winning or playing a match should **not automatically create a public post**.

After the result:

```text
Share your match?

[ Post to Timeline ]
[ Maybe Later ]
[ Don't Share ]
```

Even if napildi:

```text
Share your match?

LOSS
Riel vs Juan

[ Post Match ]
```

Kay dili lang wins ang meaningful. Pwede sila mo-post:

> "Not our day. We'll come back stronger."

So both **wins and losses** can be shared.

---

# 2. Actual Match is attached to the post

This is where PlayPanda becomes stronger than Facebook.

The user doesn't manually type:

> "I won 21-18."

The system already knows:

```text
Match
Sport
Opponent
Score
Tournament
Date
Status
Winner
```

So ang post naa'y official **Match Card**.

Example:

```text
┌──────────────────────────────┐
│ 🏸 BADMINTON                 │
│ FINAL                        │
│                              │
│ RIEL              21  21     │
│ JUAN              17  18     │
│                              │
│ ✓ VERIFIED MATCH             │
│ PlayPanda Open 2026          │
└──────────────────────────────┘
```

This gives the "proof" feeling.

# 4. Important distinction: Verified Match vs User Photo

We should avoid claiming nga ang photo itself "proves" the game happened.

Instead:

### Verified by PlayPanda

```text
✓ VERIFIED MATCH
```

means:

* actual match exists in PlayPanda
* final result exists
* tournament/scorer/opponent confirmation exists

Then:

### User-uploaded media

Photos are simply:

```text
Photos uploaded by Riel
```

So if someone uploads unrelated photo, dili ma-confuse nga gi-verify sa platform ang image itself.

# 13. Game History vs Timeline

Important nga separate ni sila.

### Match History

Official records only.

```text
WIN
LOSS
WIN
WIN
LOSS
```

Cannot simply delete official history.

### Timeline

User-controlled social posts.

User can:

* post
* edit caption
* delete post
* hide post

Even if i-delete niya ang timeline post, ang **official match record remains**.

Very important.

## So ang social side sa PlayPanda becomes:

**Profile** → who are you as a player
**Match History** → official record
**Timeline** → what you choose to share
**Follow** → whose activity you want to see
**Feed** → activity from your sports network
**Challenge** → actually play with that person
**Tournament** → formal competition
**Leaderboard** → competitive ranking

Mao ni akong makita nga strongest ecosystem sa PlayPanda.
